Features

Built for agent-to-payment trust

AgentPay bridges the gap between autonomous agents and secure financial operations.

🔑

API Key Vaulting

Encrypt and store API keys in a secure vault. Agents access them via signed tokens — raw keys never reach the agent's context.

📋

Spending Policies

Per-agent and per-session budgets with configurable limits, rate caps, and auto-top-up rules. Your money, your rules.

👤

Human Approval

Every payment above your threshold triggers a QR code or OTP. Scan to approve — the agent waits for your signal.

📊

Audit Trails

Every API call and every transaction is logged with timestamps, agent IDs, and payload hashes. Immutable and exportable.

🔌

Multi-Provider

Drop-in support for Stripe, UPI, Razorpay, and more. Switch providers without changing your agent's code.

⚡

MCP-Native

Built on the Model Context Protocol. Works with any MCP-compatible client out of the box — zero integration work.

Quick start

Go from zero to spending

Get AgentPay running in your terminal in under a minute.

📦 Installation

# Install via npx
npx @agentpayxyz/mcp-server

# Or install globally
npm install -g @agentpayxyz/mcp-server

# Start with a budget
agentpay start --budget 50

🔧 Configuration

# Set your Stripe API key
agentpay config set \
  --provider stripe \
  --key sk_live_...

# Add to MCP client config
{
  "mcpServers": {
    "agentpay": {
      "command": "npx",
      "args": ["@agentpayxyz/mcp-server"]
    }
  }
}
